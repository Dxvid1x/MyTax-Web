1. **กรอกรายได้** — ใส่เงินเดือนและโบนัสของปีนี้ MyTax รวมยอดทั้งปีให้ ไม่ต้องนั่งบวกเอง
2. **เข้าใจภาษี** — ดูว่าเงินส่วนไหนถูกนำมาคิดภาษี หลังหักค่าใช้จ่ายและค่าลดหย่อน
