# MyTax — หน้าอยากลดภาษี

อัปเดตและตรวจแหล่งข้อมูล 2026-10-03

## การใช้งาน

กด “อยากลดภาษี” จากผลคำนวณ หรือ “ลดภาษี” ในเมนู เพื่อเปิด #reduce แยกจากหน้าคำนวณ ภาพสาธิตอธิบายว่าเพิ่มสิทธิ์ลดเงินได้สุทธิอย่างไร จากนั้นเลือกหมวดและดูทีละสิทธิ์ ข้อความเงื่อนไขยาวเปิดอ่านเพิ่มได้

| หมวด | ตัวเลือก | ทดลองผลใน MyTax |
|---|---|---|
| กองทุน | RMF, Thai ESG | RMF |
| ประกัน | ชีวิต, สุขภาพตัวเอง | ทั้งสอง |
| สิทธิ์จากสิ่งที่มี | ประกันสังคม ม.33, ดอกเบี้ยบ้าน, ครอบครัว, บริจาค | ประกันสังคม |

RMF แสดงภาพนโยบายตราสารหนี้ / ผสม / หุ้น กราฟเป็นภาพสมมติแสดงความผันผวน ไม่ใช่ผลตอบแทนจริง ไม่จัดอันดับหรือแนะนำกองทุนรายตัว ทุกสิทธิ์มีลิงก์แหล่งอ้างอิง

เมื่อแผนยังไม่ครบ จะใช้ข้อมูลตัวอย่างและติดป้ายชัดเจน ปุ่มให้ไปกรอกข้อมูลของตัวเอง ไม่ใส่ข้อมูลตัวอย่างทับแผนจริง เมื่อแผนครบ สามารถปรับยอดรวม ทดลอง แล้วนำยอดแทนที่กลับไปหน้าผลภาษีได้ โดยตรวจ eligibility และเพดานร่วม ตัวเลขภาษีที่ลดกับเงินที่จ่ายเพิ่มแสดงแยกกัน

## ภาพเคลื่อนไหว

- หน้าแรกมี 11 ขั้น: เงินเดือน, โบนัส, ลดหย่อน, ภาษีที่บริษัทจ่ายไว้, กดคำนวณ, อ่านผล, กดอยากลดภาษี, สำรวจหน้าใหม่, ปรับ RMF, เปรียบเทียบ, เริ่มใช้จริง
- การเปิดหน้าใหม่ใน autoplay เป็นภาพจำลอง ไม่เปลี่ยน URL อัตโนมัติ ผู้ใช้กดปุ่มจึงไปหน้า #reduce จริง
- ปุ่มวงกลม pause/restart ถูกนำออก คงตัวเลือกขั้นตอน คำอธิบายสองบรรทัด และแถบความคืบหน้าไว้
- การพัก/วนใหม่อยู่ใน disclosure “การแสดงภาพ” เพื่อให้ยังควบคุม motion ได้
- เดโมวนเมื่อผลลัพธ์อยู่ในจออย่างน้อย 15%; เลื่อนพ้นจอ/ซ่อนแท็บจะพัก; เปลี่ยนฟีเจอร์ยกเลิก timer; ทดลองแก้ตัวเลขเองหยุด autoplay
- บทเรียนหน้าใหม่วนสามฉากเมื่อเห็นอย่างน้อย 25%; เลือกฉากเองจะพัก; ทั้งสองเคารพ prefers-reduced-motion

## ขอบเขตกฎ

เครื่องคำนวณยังรองรับปี 2568 / 2025 เงินเดือนและโบนัสตาม TAX-RULES.md ไม่ได้เพิ่ม engine ปี 2569 และการซื้อหรือจ่ายหลังปี 2025 ไม่ได้ลดภาษีปี 2568 ย้อนหลัง

Thai ESG ดอกเบี้ยบ้าน ครอบครัวและบริจาคเป็นข้อมูลการเรียนรู้ ยังไม่รวมในผลคำนวณ มีข้อความบอกข้อจำกัดชัดเจน ประกันบำนาญและกองทุนเกษียณอื่นร่วมยังนอกขอบเขต RMF trial จึงต้องยืนยันว่าไม่มีรายการดังกล่าวร่วม

อ้างอิงหลัก: [คู่มือ ภ.ง.ด.91 ปี 2568](https://www.rd.go.th/fileadmin/tax_pdf/pit/2568/Ins91_241268.pdf), [ก.ล.ต. เกณฑ์ Thai ESG สำหรับหน่วยซื้อปี 2567–2569](https://www.sec.or.th/TH/Pages/News_Detail.aspx?SECID=11027), [กรมสรรพากร: ภาษีหัก ณ ที่จ่าย](https://www.rd.go.th/14929.html).

## การตรวจ

19 automated tests ผ่าน: tax boundaries, integer satang, eligibility, insurance shared caps, RMF caps, replacement scenarios, unknown withholding, ledger/CSV และ saved data ส่วน production TypeScript/Vite build ผ่าน

Browser ใช้ข้อมูลสมมติ ไม่เปิดบันทึกในเครื่อง: RMF 30,000 → 60,000 ให้ภาษี 20,100 → 17,100 / เงินเพิ่ม 30,000; health 15,000 → 25,000 ลดภาษี 1,000; นำ RMF กลับแผนจริงที่หักไว้ 32,000 ให้ผลขอคืนโดยประมาณ 14,900 ตรวจการเปิดหน้าใหม่จริงและจำลอง autoplay ครบรอบ และตรวจ desktop 1280/mobile 390 ไม่ล้นแนวนอน ไม่พบ console error/warning

ยังเป็น local preview ไม่มีการซื้อผลิตภัณฑ์หรือส่งรายการไปกรมสรรพากร และยังไม่ได้ตรวจ native print dialog
