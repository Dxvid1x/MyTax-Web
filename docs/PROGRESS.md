## Known limits

- Individual salary/bonus calculator, not a return-filing service. Freelance/foreign income, severance, joint spouse filing, pension insurance/other retirement schemes, Thai ESGX/LTF transfers, age/disability exemptions, and temporary/special donation programs remain outside the scope. The Q&A and results warn when such cases are reported. Zero tax does not remove filing obligations.
- 2569 planning uses standing rules checked 2026-10-03; final filing and future law changes require review. Family eligibility, PVD wage base and allocated mortgage amounts depend on user-provided evidence. Direct government hospital donations 2x and ordinary eligible donations 1x only; other 2x donation types are excluded.
- Local data is tied to browser/origin and is not encrypted. Account sync and its API entry point have been removed in favour of local CSV/Excel Statement imports. Export JSON before changing devices or clearing browser data. Quota/private browsing can prevent persistence; no shared ZIP was edited or generated. `.env*` and `.vercel` are excluded from git/deploy and must be excluded from any manual shared archive.
- Undo retains the last deleted row while the ledger screen remains mounted. Recurring previews process at most 120 rounds per template per confirmation and 10,000 total rows. Repeat again for a longer backlog. Up to 32 custom categories per type and 100 templates.
- Browser unload warnings depend on interaction/browser support. Multi-key localStorage is not a server transaction system. Unknown future schemas need explicit migrations.
- Offline works after a complete online load in a supporting secure browser. Installed app and browser data use the same origin. Updating does not auto-reload unsaved work; the user confirms refresh. OS install behavior varies.
- Automated accessibility checks plus keyboard/viewport tests do not substitute for human screen-reader/user evaluation. CI is configured; remote CI needs a connected repository.
