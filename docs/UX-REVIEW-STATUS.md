|---|---|
| 1. ตัวหนังสือมือถือเล็ก | ยกข้อความเล็กใน CSS เป็นอย่างน้อย 14 px และคำอธิบาย/เงื่อนไข/สถานะสำคัญเป็น 15 px ปรับสีปุ่มเดโมโหมดมืดตามผล contrast check |
| 2. รายได้มีคำถาม 7 ข้อ | ขั้นรายได้มีเงินเดือน จำนวนเดือน โบนัส; คำถามเลือกสิทธิ์ 4 ข้ออยู่ในตัวช่วยที่เปิดดูได้ในขั้นลดหย่อน กรณีนอกขอบเขต 3 ข้อและการยืนยันอยู่ก่อนดูผล |
| 3. เดโมสับสนกับข้อมูลจริง | ป้าย “ลองเล่นข้อมูลตัวอย่าง — ไม่ใช่ข้อมูลของคุณ” เด่นขึ้น เริ่มลูปภาพรวม 5 ช่วง แล้วเลือกดูครบ 11 ขั้นได้ ข้อมูลเดโมแยกจากแผนจริง |
| 4. ลดภาษีเริ่มจากกองทุน | เริ่มหมวดสิทธิ์จากสิ่งที่มี โดยเปิดประกันสังคมก่อน หมวดลงทุน/ประกันอธิบายแยกยอดจ่ายแล้วกับการตัดสินใจจ่ายเพิ่ม |
| 5. สมุดเงินเริ่มจากตัวกรอง | ปุ่มจดเงินเข้า/เงินออกอยู่ก่อนเครื่องมือสรุป เปิดค้นหาและกรองเมื่อจำเป็น ไม่แสดงวงเงินเปล่า/กราฟเปล่าเมื่อไม่มีข้อมูล |
| 6. สถานะบันทึกกำกวม | แสดงยังไม่เปิดบันทึก / กำลังบันทึก / บันทึกในเครื่องแล้ว / บันทึกมีปัญหา และมีทางเปิดบันทึกจากหน้าแรกและรายได้ |

- ย้ายขั้นภาษีของเงินได้สุทธิบาทถัดไปเข้า “ดูวิธีคำนวณ”
- ธีมและติดตั้งแอปอยู่ใน “ตั้งค่า”; ล้างทั้งหมดอยู่ในจัดการข้อมูลที่เดียว
- ปุ่มใช้ “สำรองข้อมูล (JSON)”, “ดาวน์โหลดตาราง (CSV)” และ “กองทุนที่ทำงานช่วยออม (PVD / กบข.)”
- “ยังไม่แน่ใจ” เก็บแยกจาก “ไม่มี” นำเข้า/สำรองได้ และเตือนผลไม่ครบเมื่อยังไม่เช็กกรณีนอกขอบเขต
- เพิ่มภาพจำลองตำแหน่งเงินเดือนก่อนหักบนสลิป/50 ทวิ พร้อมข้อความว่าเอกสารจริงอาจต่างกัน
- ผลคำนวณมีข้อความแนะนำขั้นต่อไปตามสถานะยอดภาษีที่บริษัทหักไว้
- ไม่เปลี่ยนสูตร/เพดานภาษีในรอบนี้ และคงการยืนยันสิทธิ์ก่อนใช้ยอดลดหย่อน
