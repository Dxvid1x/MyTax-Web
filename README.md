# MyTax

เว็บภาษีและสมุดเงินสำหรับผู้มีเงินเดือน ไม่ต้องสมัครสมาชิก คำนวณในเบราว์เซอร์
เว็บออนไลน์: https://mytax-indol.vercel.app

ลิงก์แต่ละหน้า: `/tax` คำนวณภาษี, `/ledger` สมุดเงิน, `/reduce` สำรวจสิทธิ์, `/demo` ผลตัวอย่าง
URL ไม่มี `#`; เปิดลิงก์ตรงและรีเฟรชได้ ลิงก์เก่าจะเปลี่ยนเป็น URL ใหม่อัตโนมัติ

## เปิดพัฒนา

ใช้ Node.js 24 ขึ้นไป เปิด terminal ในโฟลเดอร์นี้:

```powershell
npm.cmd ci
npm.cmd run dev
```

เปิด URL ที่ Vite แสดง (ปกติ http://127.0.0.1:5173)

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run format:check
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

E2E ใช้เบราว์เซอร์ทดสอบแยกและข้อมูลจำลอง พอร์ต 5174 ไม่แตะข้อมูลในเบราว์เซอร์ที่ใช้งานอยู่
CI config อยู่ใน `.github/workflows/checks.yml` จะทำงานเมื่อเชื่อม Git repository

## ขอบเขตภาษี

เลือกปี 2568 / 2025 เพื่อตรวจยอดย้อนหลัง หรือ 2569 / 2026 เพื่อวางแผนเบื้องต้น
รองรับเงินเดือน/โบนัส ค่าลดหย่อนส่วนตัว ประกันสังคม ม.33 ประกันชีวิต/สุขภาพตนเอง RMF ครอบครัว ดอกเบี้ยบ้าน PVD/กบข. Thai ESG และเงินบริจาคประเภทที่รองรับ
ต้องยืนยันขอบเขตและสิทธิ์ก่อนดูผล ไม่ใช่การยื่นแบบหรือการรับรองยอดคืนจริง

ยังไม่รวมประกันบำนาญ/กองทุนเกษียณอื่น รายได้อื่น/ต่างประเทศ เงินชดเชย ยื่นร่วมคู่สมรส Thai ESGX/โอน LTF สิทธิ์ผู้สูงอายุ/พิการ หรือมาตรการชั่วคราว
SSF ซื้อใหม่ไม่ใช้ลดหย่อนปี 2568/2569 ให้ข้อมูลการรักษาสิทธิ์หน่วยเดิมในหน้าลดภาษี
ปี 2569 ใช้กฎที่ตรวจจากแหล่งทางการ ณ 2026-10-03 สำหรับการวางแผน และอาจต้องปรับก่อนยื่นแบบจริง
ใช้ยอดประกันสังคมที่จ่ายจริง ไม่ใช้เพดานแทนยอดของผู้ใช้
หลักฐานและตัวอย่างคำนวณอยู่ใน `docs/TAX-RULES.md` ตัวเลขแยกตามปีใน `src/tax.ts`

## ข้อมูลของฉัน

เปิดบันทึกในเครื่องได้ผ่านปุ่มจัดการข้อมูล การพักบันทึกเก็บสำเนาล่าสุดไว้และหยุดเก็บการเปลี่ยนแปลงใหม่
ปุ่มล้างข้อมูลต้องยืนยันแยก สมุดเงินจะเสนอให้เปิดบันทึกหลังเพิ่มรายการแรก
ใช้ key `mytax.local.v2` และย้ายข้อมูลจาก `bahtwise.local.v1` / `mytax.local.v1`
schema 3 ของสมุดเงินแยกจากรุ่นกฎภาษี ข้อมูลที่กู้ได้จะแสดงให้ตรวจ พร้อมพักการเขียนทับและสำรองต้นฉบับก่อนบันทึกใหม่
อีกแท็บเปลี่ยนข้อมูลจะพักการบันทึกเพื่อให้สำรองและโหลดข้อมูลล่าสุด

สำรองและนำเข้าทั้งแผนภาษี/สมุดเงินเป็น JSON ได้ โดยมีการตรวจไฟล์และยืนยันก่อนแทนข้อมูล
เก็บไฟล์ไว้ในที่ส่วนตัว ไฟล์สำรองและ localStorage ไม่เข้ารหัส
เมนูตั้งค่า → บันทึก แสดงสถานะและจัดการบันทึกในเครื่อง ระบบบัญชี/ซิงก์และ API ถูกนำออกจากเว็บแล้ว
ข้อมูลผูกกับ origin และโปรไฟล์เบราว์เซอร์ การเปลี่ยนจาก localhost ไป Vercel ไม่ย้ายข้อมูลตาม ให้ใช้ JSON
ล้างข้อมูลในเว็บไม่ลบไฟล์ที่ดาวน์โหลด การล้างข้อมูลเบราว์เซอร์หรือ quota เต็มอาจทำให้สำเนาในเครื่องหาย

สมุดเงินไม่ส่งยอดเข้าภาษีอัตโนมัติ มีปุ่มนำเงินเดือนตามปีที่เลือกโดยยืนยันเองและตรวจยอดก่อนหัก
ค้นหา/กรอง จัดหมวดเอง คืนรายการที่ลบ และตั้งรายการประจำได้ โดยรอบถัดไปต้องยืนยันก่อนเพิ่ม
สรุปสัปดาห์จันทร์–อาทิตย์ เดือนและปีปฏิทิน วันที่ปัจจุบันใช้ Asia/Bangkok เงินเก็บเป็นสตางค์ integer
CSV ส่งออกเฉพาะช่วงและตัวกรองที่เลือก วันที่ ค.ศ. YYYY-MM-DD หน้าผลภาษีพิมพ์/บันทึก PDF ผ่านระบบพิมพ์เบราว์เซอร์
ฟอนต์ WOFF2 อยู่ใน `public/fonts` พร้อม OFL license แผนภาษีคำนวณในเครื่อง
นำเข้า Statement แบบ CSV หรือ Excel (.xlsx) ในเครื่องได้ โดยจับคู่คอลัมน์ ตรวจวันและยอด เลือกรายการ และยืนยันก่อนเพิ่ม ไม่เชื่อมธนาคาร ไม่อัปโหลดไฟล์ และไม่เปลี่ยนแผนภาษี รองรับไฟล์ไม่เกิน 5 MB/10,000 รายการ ยังไม่รองรับ PDF/.xls/ไฟล์ใส่รหัสผ่าน

สถานะปัจจุบัน: `docs/PROGRESS.md` หลักฐานทดสอบ: `docs/VALIDATION.md`
อัปเดตออนไลน์: `docs/MYTAX-DEPLOYMENT.md`
ห้ามแนบ `.env*`, `.vercel`, `node_modules` หรือไฟล์การเงินส่วนตัวเมื่อส่งสำเนาโปรเจกต์

## ติดตั้งและออฟไลน์

ปุ่มติดตั้งแอปแสดงวิธีตามเบราว์เซอร์ เปิดออนไลน์ให้โหลดครบก่อนใช้ออฟไลน์
Production service worker เก็บเฉพาะไฟล์เว็บ ฟอนต์ และหน้าฟีเจอร์ ไม่เก็บหรือส่งข้อมูลการเงิน
มีอัปเดตแล้วจะให้กดยืนยันรีโหลดเอง สำรองข้อมูลก่อนอัปเดตหากยังไม่เปิดบันทึก
เลือกธีมสว่าง มืด หรือตามเครื่องได้ ไม่กระทบแผนภาษี
ข้อจำกัดและรายการเทียบรีวิว: `docs/PROGRESS.md`, `docs/REVIEW-STATUS.md`
